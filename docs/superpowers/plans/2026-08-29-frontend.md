# Frontend (client/) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `client/` workspace (React + Vite + TS + Tailwind) that consumes the already-built, already-reviewed backend API: professional auth, service-type/availability/blocked-slot/agenda CRUD in a protected panel, and the public per-slug booking flow — styled per `DESIGN.md`.

**Architecture:** A single-page app (React Router) with two route trees sharing one API client and design-token base: `/login`, `/registro` (public), `/painel/*` (protected panel, JWT access-token-in-memory + httpOnly-cookie silent refresh), and `/:slug` (public booking flow, no auth). TanStack Query owns all server state; react-hook-form + zod own all form state, with dynamic per-service-type intake forms built from the same `CustomFormField` shape the server already validates against.

**Tech Stack:** React 18, Vite 5, TypeScript 5.5, Tailwind CSS 3.4, React Router 6, TanStack Query 5, react-hook-form 7 + zod 3 (already used server-side — same version), date-fns/date-fns-tz 3 (already used server-side — same version), Vitest 4 + React Testing Library.

**Spec:** `docs/superpowers/specs/2026-08-27-agendamento-multi-nicho-design.md` (§3 tech stack, §9 API surface, §13 folder structure, §14 build phases 6-9). Visual source of truth: `DESIGN.md` (root). Executors read all three alongside this plan.

## Global Constraints

- API base URL: `http://localhost:3000` in dev, overridable via `VITE_API_URL` — never hardcode elsewhere.
- Client dev server: Vite default port 5173 — matches the server's `CLIENT_ORIGIN` default (`server/.env.example`); do not change the dev port without also updating that env var.
- Every panel API call sends `Authorization: Bearer <accessToken>`; every API call (panel and public) sends `credentials: 'include'` so the httpOnly refresh cookie round-trips.
- Access token lives in memory only (React state) — never `localStorage`/`sessionStorage` (CLAUDE.md §7: XSS exposure). Session survives a page refresh via a silent `POST /auth/refresh` on app mount, not via stored tokens.
- Dates/times: compute and compare in UTC; convert to the professional's `timezone` (from `/me` or `/public/:slug`) only at the display layer (CLAUDE.md §1, spec §5). Use `date-fns-tz`'s `formatInTimeZone`/`toZonedTime` for every user-facing date/time render — never `new Date().toString()`.
- `DESIGN.md`'s token values (hex colors, px sizes, font families) are the literal source of truth for `tailwind.config.ts` — copy exact values, no approximation.
- UI copy is in Portuguese, matching the server's own error strings (e.g. `"Não autenticado"`) and `DESIGN.md`'s component copy (e.g. "Confirmar agendamento"). Code, comments, identifiers, and commit messages stay in English per CLAUDE.md §1.
- No secret ever ships in client code or a `VITE_`-prefixed env var — only `VITE_API_URL` is needed.
- Follow Conventional Commits (CLAUDE.md §14.1); one logical change per commit.

```tsx
import { forwardRef, type InputHTMLAttributes } from 'react'
import { cx } from '../lib/cx'

interface InputProps extends InputHTMLAttributes<HTMLInputElement> {
  label: string
  error?: string
}

export const Input = forwardRef<HTMLInputElement, InputProps>(function Input(
  { label, error, id, className, ...props },
  ref,
) {
  return (
    <div className="flex flex-col gap-xxs">
      <label htmlFor={id} className="font-sans text-body-sm text-body">
        {label}
      </label>
      <input
        ref={ref}
        id={id}
        aria-invalid={error ? 'true' : undefined}
        className={cx(
          'h-11 rounded-md border bg-surface px-[14px] font-sans text-body-md text-ink',
          'focus:outline-none focus:border-primary',
          error ? 'border-error' : 'border-hairline',
          className,
        )}
        {...props}
      />
      {error && <span className="font-sans text-body-sm text-error">{error}</span>}
    </div>
  )
})
```

```ts
const API_BASE = import.meta.env.VITE_API_URL ?? 'http://localhost:3000'

let accessToken: string | null = null

export function setAccessToken(token: string | null) {
  accessToken = token
}

export function getAccessToken(): string | null {
  return accessToken
}

export class ApiError extends Error {
  status: number
  details?: unknown
  constructor(status: number, message: string, details?: unknown) {
    super(message)
    this.status = status
    this.details = details
  }
}

async function parseErrorBody(res: Response): Promise<{ error: string; details?: unknown }> {
  try {
    return await res.json()
  } catch {
    return { error: 'Erro desconhecido' }
  }
}

async function tryRefresh(): Promise<boolean> {
  const res = await fetch(`${API_BASE}/api/auth/refresh`, { method: 'POST', credentials: 'include' })
  if (!res.ok) return false
  const data = (await res.json()) as { accessToken: string }
  setAccessToken(data.accessToken)
  return true
}

async function request<T>(path: string, options: RequestInit = {}, allowRetry = true): Promise<T> {
  const headers = new Headers(options.headers)
  if (options.body) headers.set('Content-Type', 'application/json')
  if (accessToken) headers.set('Authorization', `Bearer ${accessToken}`)

  const res = await fetch(`${API_BASE}${path}`, { ...options, headers, credentials: 'include' })

  if (res.status === 401 && allowRetry && path !== '/api/auth/refresh') {
    const refreshed = await tryRefresh()
    if (refreshed) return request<T>(path, options, false)
  }

  if (!res.ok) {
    const body = await parseErrorBody(res)
    throw new ApiError(res.status, body.error, body.details)
  }

  if (res.status === 204) return undefined as T
  return (await res.json()) as T
}

export const api = {
  get: <T>(path: string) => request<T>(path),
  post: <T>(path: string, body?: unknown) =>
    request<T>(path, { method: 'POST', body: body !== undefined ? JSON.stringify(body) : undefined }),
  patch: <T>(path: string, body?: unknown) =>
    request<T>(path, { method: 'PATCH', body: body !== undefined ? JSON.stringify(body) : undefined }),
  put: <T>(path: string, body?: unknown) => request<T>(path, { method: 'PUT', body: JSON.stringify(body) }),
  delete: <T>(path: string) => request<T>(path, { method: 'DELETE' }),
}
```

```tsx
import { createContext, useContext, useEffect, useState, type ReactNode } from 'react'
import { api, ApiError, setAccessToken, getAccessToken } from './api'
import type { AuthUser, MeResponse } from './types'

interface AuthContextValue {
  user: AuthUser | null
  accessToken: string | null
  isLoading: boolean
  login: (user: AuthUser, accessToken: string) => void
  logout: () => Promise<void>
}

const AuthContext = createContext<AuthContextValue | null>(null)

async function silentRefresh(): Promise<boolean> {
  try {
    // A GET that requires auth doubles as the refresh trigger: api.ts's request()
    // retries any 401 via POST /auth/refresh automatically, and /api/me is the
    // lightest authenticated endpoint that exists for this purpose.
    await api.get<MeResponse>('/api/me')
    return true
  } catch {
    return false
  }
}

export function AuthProvider({ children }: { children: ReactNode }) {
  const [user, setUser] = useState<AuthUser | null>(null)
  const [token, setToken] = useState<string | null>(null)
  const [isLoading, setIsLoading] = useState(true)

  useEffect(() => {
    async function bootstrap() {
      const ok = await silentRefresh()
      if (ok) {
        try {
          const me = await api.get<MeResponse>('/api/me')
          setUser({ id: me.id, name: me.name, email: me.email, slug: me.slug })
          setToken(getAccessToken())
        } catch {
          setAccessToken(null)
        }
      }
      setIsLoading(false)
    }
    bootstrap()
  }, [])

  const login = (u: AuthUser, accessToken: string) => {
    setAccessToken(accessToken)
    setUser(u)
    setToken(accessToken)
  }

  const logout = async () => {
    try {
      await api.post('/api/auth/logout')
    } catch {
      // Best-effort: even if the network call fails, clear local state below.
    }
    setAccessToken(null)
    setUser(null)
    setToken(null)
  }

  return (
    <AuthContext.Provider value={{ user, accessToken: token, isLoading, login, logout }}>
      {children}
    </AuthContext.Provider>
  )
}

export function useAuth(): AuthContextValue {
  const ctx = useContext(AuthContext)
  if (!ctx) throw new Error('useAuth must be used within AuthProvider')
  return ctx
}

export { ApiError }
```

```ts
import { api } from '../../../lib/api'
import type { ServiceType, ServiceTypeInput } from '../../../lib/types'

const KEY = ['service-types'] as const

export function useServiceTypes() {
  return useQuery({ queryKey: KEY, queryFn: () => api.get<ServiceType[]>('/api/service-types') })
}

export function useCreateServiceType() {
  const queryClient = useQueryClient()

}
```

```tsx
import type { AvailabilityRule } from '../../../lib/types'

const DAYS = [
  { dayOfWeek: 0, label: 'Domingo' },
  { dayOfWeek: 1, label: 'Segunda-feira' },
  { dayOfWeek: 2, label: 'Terça-feira' },
  { dayOfWeek: 3, label: 'Quarta-feira' },
  { dayOfWeek: 4, label: 'Quinta-feira' },
  { dayOfWeek: 5, label: 'Sexta-feira' },
  { dayOfWeek: 6, label: 'Sábado' },
]

const DEFAULT_START = '09:00'
const DEFAULT_END = '18:00'

interface WeeklyScheduleEditorProps {
  value: AvailabilityRule[]
  onChange: (rules: AvailabilityRule[]) => void
}

export function WeeklyScheduleEditor({ value, onChange }: WeeklyScheduleEditorProps) {
  function toggleDay(dayOfWeek: number) {
    const existing = value.find((r) => r.dayOfWeek === dayOfWeek)
    if (existing) {
      onChange(value.filter((r) => r.dayOfWeek !== dayOfWeek))
    } else {
      onChange([...value, { dayOfWeek, startTime: DEFAULT_START, endTime: DEFAULT_END }])
    }
  }

  function updateTime(dayOfWeek: number, field: 'startTime' | 'endTime', time: string) {
    onChange(value.map((r) => (r.dayOfWeek === dayOfWeek ? { ...r, [field]: time } : r)))
  }

  return (
    <div className="flex flex-col gap-sm">
      {DAYS.map(({ dayOfWeek, label }) => {
        const rule = value.find((r) => r.dayOfWeek === dayOfWeek)
        return (
          <div key={dayOfWeek} className="flex items-center gap-md">
            <label className="flex w-40 items-center gap-xs font-sans text-body-sm text-body">
              <input type="checkbox" checked={rule !== undefined} onChange={() => toggleDay(dayOfWeek)} />
              {label}
            </label>
            {rule && (
              <>
                <label className="font-sans text-body-sm text-muted">
                  Início — {label}
                  <input
                    type="time"
                    value={rule.startTime}
                    onChange={(e) => updateTime(dayOfWeek, 'startTime', e.target.value)}
                    className="ml-xs rounded-md border border-hairline p-xs"
                  />
                </label>
                <label className="font-sans text-body-sm text-muted">
                  Fim — {label}
                  <input
                    type="time"
                    value={rule.endTime}
                    onChange={(e) => updateTime(dayOfWeek, 'endTime', e.target.value)}
                    className="ml-xs rounded-md border border-hairline p-xs"
                  />
                </label>
              </>
            )}
          </div>
        )
      })}
    </div>
  )
}
```

```tsx
import { useEffect, useState } from 'react'
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query'

  })

      <Button className="mt-lg" onClick={() => save.mutate(rules)}>
        Salvar
      </Button>
    </Card>

}
```

```tsx
import { useState } from 'react'
import { formatInTimeZone, toZonedTime } from 'date-fns-tz'
import { cx } from '../../lib/cx'

interface CalendarPickerProps {
  selectedDate: string
  onSelectDate: (date: string) => void
  timezone: string
  now?: Date
}

export function CalendarPicker({ selectedDate, onSelectDate, timezone, now = new Date() }: CalendarPickerProps) {
  const [viewMonth, setViewMonth] = useState(() => selectedDate.slice(0, 7)) // "YYYY-MM"
  const todayStr = formatInTimeZone(now, timezone, 'yyyy-MM-dd')

  const [year, month] = viewMonth.split('-').map(Number)
  const firstOfMonth = new Date(Date.UTC(year, month - 1, 1))
  const daysInMonth = new Date(Date.UTC(year, month, 0)).getUTCDate()
  const startWeekday = toZonedTime(firstOfMonth, timezone).getUTCDay()

  const cells: Array<{ dateStr: string; day: number } | null> = []
  for (let i = 0; i < startWeekday; i++) cells.push(null)
  for (let day = 1; day <= daysInMonth; day++) {
    const dateStr = `${viewMonth}-${String(day).padStart(2, '0')}`
    cells.push({ dateStr, day })
  }

  function shiftMonth(delta: number) {
    const next = new Date(Date.UTC(year, month - 1 + delta, 1))
    setViewMonth(`${next.getUTCFullYear()}-${String(next.getUTCMonth() + 1).padStart(2, '0')}`)
  }

  return (
    <div>
      <div className="mb-sm flex items-center justify-between">
        <button onClick={() => shiftMonth(-1)} aria-label="Mês anterior" className="text-muted hover:text-ink">
          ‹
        </button>
        <span className="font-sans text-title-sm text-ink">{viewMonth}</span>
        <button onClick={() => shiftMonth(1)} aria-label="Próximo mês" className="text-muted hover:text-ink">
          ›
        </button>
      </div>
      <div className="grid grid-cols-7 gap-xxs">
        {cells.map((cell, i) => {
          if (!cell) return <div key={`empty-${i}`} />
          const isPast = cell.dateStr < todayStr
          const isSelected = cell.dateStr === selectedDate
          return (
            <button
              key={cell.dateStr}
              disabled={isPast}
              onClick={() => onSelectDate(cell.dateStr)}
              aria-label={String(cell.day)}
              className={cx(
                'h-11 w-11 rounded-full font-sans text-body-sm',
                isSelected && 'bg-primary text-on-primary',
                !isSelected && !isPast && 'text-ink hover:bg-surface-soft',
                isPast && 'cursor-not-allowed text-muted-soft',
              )}
            >
              {cell.day}
            </button>
          )
        })}
      </div>
    </div>
  )
}
```

```ts
import { z } from 'zod'
import type { ServiceTypeCustomField } from './types'

// Mirrors server/src/modules/bookings/form-validation.ts's validateFormResponses
// exactly: required check, per-fieldType check, SELECT restricted to `options`.
export function buildCustomFieldsSchema(fields: ServiceTypeCustomField[]) {
  const shape: Record<string, z.ZodTypeAny> = {}
  for (const field of fields) {
    let fieldSchema: z.ZodTypeAny
    switch (field.fieldType) {
      case 'TEXT':
      case 'TEXTAREA':
        fieldSchema = z.string()
        break
      case 'NUMBER':
        fieldSchema = z.coerce.number({ invalid_type_error: `O campo "${field.label}" deve ser numérico` })
        break
      case 'SELECT': {
        const options = field.options ?? []
        fieldSchema =
          options.length > 0
            ? z.enum(options as [string, ...string[]], {
                errorMap: () => ({ message: `O campo "${field.label}" tem um valor inválido` }),
              })
            : z.string().refine(() => false, { message: `O campo "${field.label}" não tem opções configuradas` })
        break
      }
    }
    shape[field.id] = field.required
      ? fieldSchema.refine((v) => v !== undefined && v !== '', { message: `O campo "${field.label}" é obrigatório` })
      : fieldSchema.optional()
  }
  return z.object(shape)
}

export function buildBookingFormSchema(fields: ServiceTypeCustomField[]) {
  return z
    .object({
      clientName: z.string().min(1, 'Nome é obrigatório'),
      clientEmail: z.string().email('E-mail inválido'),
    })
    .merge(buildCustomFieldsSchema(fields))
}
```

````markdown
# Agendamento Multi-Nicho

SaaS de agendamento (estilo Calendly) para profissionais autônomos de
diferentes nichos (psicólogos, personal trainers, etc.), cada um com seus
próprios tipos de atendimento, disponibilidade e formulários customizados.
Clientes agendam por um link público, sem login.

## Arquitetura

- `server/` — API REST (Express + TypeScript + Prisma + PostgreSQL).
- `client/` — SPA (React + Vite + TypeScript + Tailwind).
- Autenticação: JWT de acesso (em memória no cliente) + refresh token em
  cookie httpOnly, com renovação silenciosa no carregamento do app.
- Cálculo de horários disponíveis (`server/src/modules/availability/engine.ts`):
  função pura que cruza a disponibilidade geral do profissional, as regras
  específicas por tipo de serviço (quando existem — substituem, não somam,
  a disponibilidade geral daquele dia) e os conflitos (agendamentos
  confirmados + bloqueios manuais), fatiando em slots do tamanho exato da
  duração do serviço escolhido. Tudo calculado e armazenado em UTC,
  convertido para o fuso do profissional só na exibição.
- Concorrência (`server/src/modules/bookings/bookings.service.ts`): toda
  criação de agendamento público primeiro re-valida o horário pedido contra
  essa mesma função de disponibilidade (nunca confia no horário que o
  cliente mandou) e depois insere protegido por uma constraint `EXCLUDE`
  no Postgres — se dois clientes tentarem o mesmo horário ao mesmo tempo,
  o banco garante que só um agendamento é criado.

## Rodando localmente

Pré-requisitos: Node 20+, Docker.

```bash
npm install
docker compose up -d postgres
cp server/.env.example server/.env    # edite JWT_SECRET
cp client/.env.example client/.env
npm run --workspace server db:migrate  # aplica as migrations do Prisma
npm run --workspace server db:seed     # cria os 2 profissionais de exemplo
npm run dev:server                     # http://localhost:3000
npm run dev:client                     # http://localhost:5173 (outro terminal)
```
````

Profissionais de exemplo (senha `demo1234` para ambos):

- `/joana-psicologa` — Psicologia
- `/carlos-personal` — Personal Trainer

## Variáveis de ambiente

**`server/.env`** (ver `server/.env.example`):

- `DATABASE_URL` — string de conexão do Postgres.
- `JWT_SECRET` — 32+ caracteres aleatórios.
- `PORT` — porta da API (padrão 3000).
- `CLIENT_ORIGIN` — origem permitida por CORS (padrão `http://localhost:5173`).

**`client/.env`** (ver `client/.env.example`):

- `VITE_API_URL` — URL base da API (padrão `http://localhost:3000`).

## Deploy

Instruções, não provisionamento — nenhuma infraestrutura foi de fato criada
como parte deste projeto.

**Frontend (Vercel):** conectar o repositório, definir o _root directory_
como `client/`, build command `npm run build`, output `dist/`. Configurar
`VITE_API_URL` apontando para a URL pública da API.

**Backend (Render ou Railway):** conectar o repositório, _root directory_
`server/`, build command `npm install && npx prisma migrate deploy && npm run build`,
start command `npm start`. Provisionar um banco Postgres gerenciado na
mesma plataforma e apontar `DATABASE_URL` para ele. Definir `JWT_SECRET`
(gerado, nunca reaproveitado de dev) e `CLIENT_ORIGIN` com a URL pública do
frontend na Vercel.
